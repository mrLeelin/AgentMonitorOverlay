# 输入框快捷项

> 状态：待确认。2026-11-28 用户希望自己配置截图中 `/` 菜单的内容，区分「公用」和「项目」。本方案建议把常用提示词和子会话设定存成可直接选用的快捷项。

## 怎么用

在项目的会话输入框或新建任务的「第一句话」里输入 `/`，先看到当前项目的快捷项，再看到公用快捷项。每组沿用现有菜单的两列布局，左边是名称，右边说明选中后会做什么。空组省略，菜单底部提供「管理快捷项…」。

```text
项目 · AmoStudio
  /验收改动           插入提示词
  /只读复核           打开子会话设定 · Codex
公用
  /总结进度           插入提示词
AMO 扩展功能
  /开子会话…         选模型、强度，补充这轮的话
  /提示词模板…       浏览和选择模板
─────────────────────────────────────────
  管理快捷项…
```

- **提示词快捷项**引用一条现有模板。选中后用最新正文替换光标处的 `/关键词`，保留其余草稿并把光标移到插入内容之后。用户可继续修改，再按原有方式发送。
- **子会话快捷项**打开现有「开子会话」弹窗，预填已保存的模型、强度、权限和补充说明等选项。用户确认后，输入框得到 `@子会话` 标签。模型或渠道不可用时，行内说明原因，并可回到设置修改。
- 输入名称片段即可筛选，用方向键和回车选中。同名快捷项可在项目和公用各出现一次，分组显示，项目项排在前面。同组名称去掉首尾空格后需唯一，英文大小写视为相同。快捷项按所选菜单行的 ID 处理，原生命令仍按现有路径匹配。
- 打开管理或取消子会话弹窗时保留原草稿和光标。选中可插入的项后才替换 `/关键词`，中文输入法组词时由输入法先处理回车。

## 在哪里配置

从「/ → 管理快捷项…」或「设置 → 工具与自动化 → 输入框快捷项」打开同一设置页。页面上方是 `公用 | 项目 ▾`。从某个项目打开时选中该项目，没有项目上下文时先选公用。项目页显示所选项目名，再列出该项目自己的快捷项。

- **公用**是本机 Studio 中所有本地项目和公共工作区都可用的个人配置，例如「总结进度」。
- **项目**仅在选定的 Studio 项目里显示，例如 AmoStudio 的「验收改动」。跟随项目 ID，同一项目切换工作树或改名后仍可用。新建任务切项目时，菜单立即跟着切换。
- 新建快捷项时填写名称、选择适用范围和类型，再选择一条提示词模板或填写子会话设定。表单默认使用当前管理页的范围。项目快捷项可引用公用模板和同一项目的模板，公用快捷项只可引用公用模板。
- 提示词模板的预览可点「加入 / 菜单」，子会话弹窗可点「另存为快捷项」。两处都进入同一个编辑表单，并带入当前内容。管理页可以改名、调整组内顺序、停用和删除。删除快捷项只解除菜单引用，模板正文继续在模板库里可用。

## 数据和接入

- 现有提示词模板已经按公用与项目存放在 Host 的 `prompt-templates`。快捷项单独存一份本地配置，用项目 ID 标范围，用模板 ID 关联正文。旧模板由本人逐条加入 `/` 菜单。模板被删除或改到该快捷项无权引用的范围时，设置页提示重新选择，菜单中隐藏该项。
- 子会话预设只存用户明确保存的选项。打开弹窗时用当前模型的有效选项校验，使用「默认」的字段随现有子会话设置取值。发送走现有 `@子会话` 引用和启动流程。
- 复用 `useComposerMentions` 的插入能力和 `SlashMenu` 的菜单定位、筛选与键盘交互。对话按 `session.workspaceId`，新建任务按所选项目 ID，尚未选项目时只显示公用。过滤同时核对当前项目与返回结果的项目，避免切换期间看到上一项目的内容。只在支持对应动作的输入框展示该类型，远程目标的模板通过现有设备模板选择器获取。
- 保存后通过 Host 变更事件刷新打开的界面。设置页保存失败时保留编辑内容并显示原因。

## 验收

1. 在项目 A 新建项目提示词快捷项，再新建一个公用快捷项。项目 A 能看到两项，项目 B、未选项目和公共工作区只看到公用项。同一项目内切工作树仍能看到项目项。快速往返切项目也不串项。
2. 会话和新建任务都能使用键盘或鼠标选中快捷项。模板插入保留前后草稿且不触发发送，取消子会话预设或从管理页返回时恢复草稿和光标。中文输入法组词不触发选项。
3. 子会话预设能预填和修改选项，确认后插入标签。模拟渠道不可用后有明确提示，旧的「提示词模板…」可继续浏览已存模板。
4. 修改模板正文后快捷项插入新正文。删除、改范围、停用和调整顺序后菜单及时更新；同名的项目与公用项可分别选用。对照现有深浅主题检查菜单和设置页。
