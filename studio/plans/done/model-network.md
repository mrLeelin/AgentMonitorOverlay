# 模型连接代理

2026-11-08 用户确认在 Studio 设置增加「网络」：跟随启动环境（默认）、手动 HTTP / HTTPS 代理、直接连接；提供连接测试，本机通信绕过代理。不改变 Windows 全局设置及用户已有的 Codex 配置。

配置保存在 Studio 数据目录的 kv `settings:network`，启动 Codex、Claude、DeepSeek 时在最终环境上覆盖代理变量的大小写形式，沿用已有的本机绕过列表并补充 localhost、IPv4 / IPv6 回环地址。手动代理暂不支持账号密码，避免把凭据写进普通设置。

保存仅影响之后启动的模型进程，不重启 Host 或中断已有会话。Codex 常驻后台需由人点击「应用到空闲 Codex 后台」释放，下一次使用时重建；运行中或交给终端的会话阻止此操作。Claude 和 DeepSeek 的已有会话需关闭后重新打开。

测试使用当前表单、不要求保存：先检查代理端口，再并行用 Windows 自带 curl 探测三个固定服务地址，不使用模型凭据或发送对话。HTTP 响应只证明可达，不代表登录、模型权限或自定义渠道可用；代理身份验证、连接超时和证书失败分别提示。测试使用 mock 代理验证直连失败而代理有响应，以及设置保存、验证拒绝与界面重新读取。
