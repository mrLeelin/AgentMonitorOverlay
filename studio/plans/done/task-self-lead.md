# 任务自行设为主控

状态：做完

## 用户决定（2026-11-09）

任务会话可以通过 AMO 工具将自己的任务设为主控，不再要求人先到任务页手动标记。

## 做法与边界

- 新增 `task_set_lead`，仅当前任务的根主会话可调用，必填交接摘要；不接受其他任务 id，不改变直属主控或接管同专题旧任务。
- 工具立即返回切换申请，当前轮结束且任务内所有会话、终端、后台命令与待送消息都安定后才切换。
- 旧 Codex、DSH 会话保留启动时的工具和权限，不能仅修改 `lead` 或 permission。归档旧会话后，复用已有任务服务将任务设为主控，再创建同模型、只读的新主控会话并送入交接摘要。旧对话保留。
- 申请与新会话 id 持久化，事件重入和 Host 重建不会重复创建；失败写入可见提示，不自动循环消耗模型额度。
- 用户点停止会取消尚未切换的申请；会话及分支创建统一计数，未落库的启动请求也要等待。旧消息在异步等待后重新检查归档状态，新主控创建后再次核对任务角色与归档状态再交接。
- 不自动重启 Host，不提交或发布。

## 验证

覆盖工具注册与调用身份、上级归属保留、当前轮和后台等待、只读主控启动、幂等、未读消息及失败恢复。12 条新增 mock 测试与相关回归共 101 条通过；类型检查和构建通过。尚未重启当前运行的 Host，未提交或发布。
