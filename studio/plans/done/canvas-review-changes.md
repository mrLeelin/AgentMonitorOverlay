# 画布审阅卡变化提醒

## 决定与范围

2026-11-08 用户同意继续实施并一起测试，按上一轮顺序推进第二批变化标记。范围为编号审阅卡；连带复查与 Focus 聚合留待后续。它不修改审阅状态，也不把「已看」等同于「已确认」。

## 做法和原因

- 比较标题、正文、结论、状态、引用五项内容。新增卡标「新增」，已有卡变化标「已更新」，悬停说明哪些字段变了。位置、分组、大小、颜色、会话列表和连线变更不触发。
- 初次打开该专题画布建立基准，已有卡不会全部变成新增。此后只有人点「本条已看」或「全部标为已看」才推进基准；打开、刷新、离开、点卡片都不自动清除。
- 顶部显示变化数量，可依次定位并打开卡片详情。小窗不建立或推进已看基准。
- 本机 localStorage 按 Host 地址和专题分开存放，使用 v1 键，只保存内容指纹，不复制正文；同源其他窗口通过 storage 事件同步。存储不可用时仅在当前页面内有效。不同设备独立，不同步到账号。
- 与最后标为已看的内容比较，不做修改历史：恢复成原内容不提示，已删除卡不列入提醒。两组 32 位指纹只用于界面变化检测，不是安全校验。
