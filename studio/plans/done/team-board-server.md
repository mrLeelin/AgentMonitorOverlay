# 独立团队看板

> 状态：已实现，待部署到团队服务器。

2026-11-24 用户确认，团队看板部署到服务器，同事用浏览器提单和验收。Studio 客户端在本地项目旁展开同一张四列看板。团队票据由服务管理，本地工作目录、任务和会话留在 Studio。

- 团队看板用「待定、进行中、审查、完成」四列，所有已登录的团队成员可看。提出人可以在提单时留空执行者，提单资料没有本地项目字段。
- Studio 从待定拖入本地待办时，服务端确认唯一执行者，原单进进行中。Studio 依服务器、账号及原单编号复用本地任务。本地写入失败时尝试撤回本次接单。若连接中断且服务端已经记录接单，同一执行者仍能接入正在进行中的原单。
- 只有执行者能送审。服务端保存给提出人的待审核通知。只有提出人可验收或退回待定，退回保留执行者。提出人和执行者都可评论和附文件。
- 看板服务是 `packages/team-board-server`，网页构建到 `dist-web`。原单、附件、历史及通知进入独立 SQLite，认证连接现有 AMO 账号服务。浏览器采用独立会话，Studio 采用平台的团队账号授权。
- Studio 的本地列继续反映本地执行情况，团队列通过接单、送审及验收操作更新。前一版已有的本地原单链接仍可在任务页打开。

启动和部署配置见 `packages/team-board-server/README.md`。端到端用例见 `e2e/studio/team-tasks.spec.ts`。
