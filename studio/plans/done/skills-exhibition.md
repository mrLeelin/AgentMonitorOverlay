# 技能展览

状态：做完（2026-11-17）

## 需求与范围

2026-11-17，用户提供其他插件的技能页面作为参考，要求在 Studio 增加技能展览。入口放在设置的「工具与自动化」，沿用当前主题、设置搜索和窗口尺寸。

页面采用「全局技能 / 项目技能 / 发现技能」切换、统计、来源分组和搜索栏。扫描本机已有的 Agent Skills，支持查看名称、描述、真实文件路径和诊断。项目选择仅提供已登记且未归档的本地项目。

展览按磁盘目录统计条目，同一技能可通过多个来源出现；这不代表运行时启用数量。模型实际加载内容继续由会话的 `$` 菜单提供。本次不加入启停、安装、删除和回收站，避免把目录发现与各工具的配置混为一谈。

## 做法

- `GET /api/skills` 无 workspaceId 返回全局目录，提供 workspaceId 时验证项目后扫描项目目录。无需创建会话或调用模型。
- 来源包含公共 Agent、Codex、Claude Code、DSH 等本机目录，系统技能和 Codex/Claude 插件缓存也可浏览。缓存名称明确标注，避免被理解为已启用插件。
- 遍历使用真实路径去重和防循环，限制深度、条目数和文件大小；缺少元数据、过大的文件、读取失败及截断都有诊断。
- 打开说明复用现有文件查看器，打开目录复用资源管理器接口。发现页链接到公开技能目录，在浏览器查看与安装；回到页面刷新即可重新扫描。
- 不提供新接口的旧 Host 显示手动重启说明；不自动重启用户的 Host。

## 验证

扫描器与 HTTP 定向测试覆盖元数据、链接、项目隔离、边界和错误；Electron 用临时技能目录验证浏览、筛选、项目切换、文件查看、旧 Host 重试、发现入口和深浅主题/窄窗口截图。
