# 任务页里的任务说明

状态：做完（2026-11-28）

用户反馈任务说明常驻在工具栏和会话之间，位置不合适。2026-11-28，用户看过预览后确认把入口和正文都放在右侧栏。

- 打开右侧栏后，在「环境」「进度和批注」后面显示「任务说明」页签。选中态沿用现有页签样式。会话列表和对话紧接工具栏。
- 侧栏沿用现有宽度和折叠入口。切换页签只替换右侧内容，保留对话滚动位置和输入草稿。展开侧栏后按现有行为恢复上一次选择。选中「任务说明」时，在同一任务内切换会话继续查看当前说明。
- 正文在侧栏内滚动，可选中复制，保留换行并自动折行。有编辑权限时显示「编辑」并复用现有说明编辑框，内容为空时显示「添加说明」。归档及只读副本根据现有权限仅提供查看。
- 「共同需求」继续通过标题区的版本入口查看。特殊的 Plane Bot 任务沿用现有原单和本地说明入口。画布和任务数据继续使用原有说明字段。

实现验收时用普通本地任务验证长说明、无说明、归档任务及窄窗口。覆盖侧栏开合、键盘切换页签、切换会话、文件预览，以及编辑保存后回到说明页签。
