# Studio 团队任务接入 Plane

状态：做完

用户决定解除 Plane 与 Studio 本地任务的强绑定。2026-11-25 按批注将切换范围限定为 Studio 右侧工作区。「团队任务」放在左栏「全部任务」上方，再点一次回到之前的本地页面。工具栏左侧显示当前 Plane 项目名称，右端齿轮打开团队连接设置。

- 团队页继承 Plane 的状态列、操作工具栏、详情及项目权限。网页会话保存在独立的 Electron 分区。
- 切回本地页面时，Studio 隐藏并在内存中保留一个 Plane 页面。连接验证通过且项目和账号匹配时复用该页面，保留详情和滚动位置。显式刷新、创建个人任务后同步执行人，以及更换项目或账号时会重新加载。
- 右侧工作区跟随 Studio 的深浅主题，主题设定只用于当前嵌入页。看板列跟随右侧可用宽度，在约 1200 像素的工作区内可同时看到五列。窄窗口继续使用 Plane 自带的横向滚动。
- 右键团队卡片或拖到左栏专题、项目可打开「创建个人任务」弹窗。弹窗复用 Studio 的新任务表单，预填原单和落点。用户可改名称、专题和项目，选择「开始」或「放进待办」。提交后保留原单编号、标题、说明、提出人和链接，把当前 Plane 账号加为执行人。个人任务上的原单链接可移除。
- 本地归档和 Plane 状态各自管理。重新生成 Plane 覆盖文件可撤销上一版对 Plane 自带创建和状态更新的拦截。
- 2026-11-25 用户决定，个人任务的「打开 Plane 原单」在 Studio 的「团队任务」工作区打开对应工作项。有可用的 Plane 页面时，用原生路由打开原单并复用当前文档。沿用该服务器在 Studio 里的 Plane 登录会话，顶部后退可返回个人任务。
- 桌面团队页使用 Plane 原生的创建流程。浏览器版 Studio 的 API 渲染入口保留本地草稿和幂等重试。
- Studio 按 AMO 账号保存 Plane 连接，令牌使用 Windows DPAPI 加密。选择器仅列出当前令牌可访问的项目。
- 2026-11-25 用户选用内置 MCP。关联原单的会话开工先调用 `plane_task_get`，按任务关联直接读取实时工作项。父项、子项及关联项可通过返回的原单链接继续查看，评论和活动等列表可分页，文件用 `plane_task_file` 按需取得。Host 使用已有 Plane 连接并校验账号，Plane 按项目与工作项权限返回可见数据。
