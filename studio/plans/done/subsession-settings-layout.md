# 子会话设置分栏

状态：做完（2026-11-11）。

## 用户决定

2026-11-11，用户在两版可点击设计中选择 A：顶部切换渠道，左侧型号列表，右侧编辑。保持现有设置窗口的风格；长说明收进「生效规则」，编辑区分成启动选项与模型用法说明。

## 做法与原因

- 型号列表提供搜索和配置状态，切换仅负责导航，不创建空记录，也不消耗保存上限。列表与编辑区各自滚动，长型号来源另起一行；较窄的设置窗口将选项标签放在控件上方。
- 「整个渠道」改为「渠道通用设置」，显示当前默认型号。沿用既有数据规则：默认型号与通用项共用 `model:null`；通用项的强度只用于默认型号，Fast 和权限可被具体型号覆盖。
- 用法面向主模型，单独填写时优先使用；编辑型号时可查看未单独填写时使用的渠道说明。没有新增向子会话自动注入用法的行为。
- 强度和 Fast 从实际型号能力读取。Fast 提供沿用、开启、关闭三态，明确保存 `false`；Pi 的只读和可写权限仍禁用。
- 保存文字与修改选项按顺序合并，防止失焦保存和下一次点击覆盖彼此。失败保留输入；恢复默认只清除启动选项，清除单独设置才移除整条记录。已隐藏渠道和已不在目录中的型号，有保存记录时仍可访问。
