# 设置二级分类

状态：做完（2026-11-11）。

## 用户决定

2026-11-11，设置入口过长，采用五个一级分类及原有页面组成的二级菜单：

| 一级分类 | 二级页面 |
|---|---|
| 通用 | 界面、项目与目录、便签 |
| 模型与会话 | 模型与渠道、子会话、提示词模板、额度、用量统计 |
| 工具与自动化 | MCP、Git 编辑器、值守 |
| 高级设置 | 网络、功能开关、测试功能 |
| 数据与维护 | 数据管理、维护 |

## 做法与原因

- 左侧一次展开一个分类，允许收起；右侧沿用原页面，避免增加一列压缩编辑区。原页面 id 保留，外部快捷入口直接展开所在分类。
- 打开一个新分类时选择它的首个页面；再次打开设置时保留当前窗口上次选择的页面及展开状态。
- 搜索跨全部分类，匹配分类名称、页面名称和关键词；只展示有结果的分类，自动展开匹配项。搜索中的页面选择作为临时预览，清空搜索恢复原页面与展开状态。
- 上下方向键及 Home/End 移动导航焦点，移到二级项时打开页面；左右方向键展开或收起所在分类，Enter/空格沿用按钮行为。搜索框的 Esc 先清空搜索。
- 分类按钮提供展开状态及对应子列表，二级项保留 tab/tabpanel 关系和选中状态。样式复用现有设置窗口及主题变量。
